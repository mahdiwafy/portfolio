## 🎨 Arsitektur & Prinsip Desain

* **Pure Performance & Zero Bloat:** Dibangun dengan Semantic HTML5 murni dan CSS kustom tanpa framework berat, menjamin kecepatan muat instan (< 100ms) dan nilai Lighthouse optimal.
* **Responsive & Adaptive:** Tampilan fluid yang menyesuaikan layar ponsel (mobile), tablet, hingga layar desktop lebar dengan tipografi Source Sans 3 & Manrope.
* **Light / Dark Mode Native:** Mendukung deteksi preferensi sistem (`prefers-color-scheme`) dan toggle manual dengan persistensi lokal (`localStorage`).
* **Web Accessibility (a11y):** Menggunakan elemen semantik `<main>`, `<section>`, `<article>`, `<dialog>`, atribut `aria-*`, serta fokus navigasi yang ramah pembaca layar (screen reader).

## 💻 Panduan Menjalankan Secara Lokal

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/mahdiwafy/portfolio.git
   cd portfolio
   ```

2. **Jalankan web server lokal:**
   * Menggunakan Python:
     ```bash
     python3 -m http.server 8080
     ```
   * Atau klik kanan `index.html` di **VS Code** lalu pilih **Open with Live Server**.

3. **Buka browser:**
   Akses `http://localhost:8080` untuk melihat tampilan portofolio.
