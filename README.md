# Portofolio Taufiq Mahdi Wafy

Portofolio single-page yang berjalan langsung di browser, dibuat dengan HTML, CSS, dan JavaScript murni.

## Menjalankan
Buka `index.html` di browser. Tombol Unduh CV ATS menggunakan path `assets/cv/CV_ATS_Taufiq_Mahdi_Wafy.pdf`; letakkan PDF CV pada path tersebut agar unduhan tersedia.

## Fitur
- Tata letak responsif untuk desktop, tablet, dan ponsel.
- Tema gelap dan terang dengan preferensi tersimpan.
- Navigasi pill mengambang dengan efek kaca.
- Filter proyek, animasi saat menggulir, dan progress bar halaman.
- Tipografi responsif dengan system font stack; tidak membutuhkan font eksternal.
- Mendukung preferensi `prefers-reduced-motion`.
